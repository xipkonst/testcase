# testcase
Simple docker compose
Скопируйте файлы в соответствующие папки, выполните `chmod +x nginx/gen-certs.sh && ./nginx/gen-certs.sh`, затем `docker-compose up -d`. Система поднимется без ошибок, все healthchecks пройдут успешно. Nginx слушает 443 с самоподписанным сертификатом, проксирует запросы в приложение с корректными заголовками, ограничивает запросы до 10 r/s и размер тела до 10 MB.
